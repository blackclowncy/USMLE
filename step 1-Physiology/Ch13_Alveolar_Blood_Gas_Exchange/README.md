# Chapter 13: Alveolar–Blood Gas Exchange (肺泡-血液气体交换)

## 章节概述 (Chapter Overview)
本章严格遵循《Kaplan Medical Preclinical Physiology Review 2023》Part V Chapter 2（pp. 164–169），全面覆盖气体分压定律（Dalton定律、水蒸气稀释）、肺泡/毛细血管/动脉血气分压动态平衡、解剖分流与生理性A-a梯度、低氧血症鉴别诊断、肺泡气体方程（PAO2）、Fick扩散定律（表面积、厚度、扩散常数、分压梯度）、灌注受限与扩散受限动力学、肺弥散量（DLCO）及其在阻塞性/限制性/血管性肺病中的鉴别应用。
