# Chapter 12: Lung Mechanics (肺呼吸力学)

## 章节概述 (Chapter Overview)
本章严格遵循《Kaplan Medical Preclinical Physiology Review 2023》Part V Chapter 1（pp. 140–163），全面覆盖肺通气力学、肺容积与肺容量、死腔与肺泡通气量、肺顺应性与表面活性物质、呼吸肌力学与胸壁力学、气道阻力与动态气道压迫、肺功能测定（PFT）与流速-容积曲线等高难度核心考点。
